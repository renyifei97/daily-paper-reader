Abstract 

We introduce the TemporallyEdgeDisjointScheduleCompletion (TEDSC ) problem in which we need to cover a set of temporal edge demands D by routing k temporal walks through a directed static graph while remaining temporally edge disjoint. This problem combines the temporal aspects of train routing and passenger demands with the static nature of real-world rail networks. We present a polynomial time algorithm for TEDSC . Motivated by real world constraints, we next investigate two restricted variants of TEDSC in which each walk can only travel for some bounded distance or time h. We show that both are tractable when parameterized by k + h, but hard for h

and k + |D|. If we fix the underlying network, the two problems exhibit distinct complexities: The distance variant remains W[1] -hard parameterized by k even on a path of three vertices whereas the time variant admits an FPT algorithm on any fixed star. Finally, we show how to approximate the number of required walks up to a factor of (2 − h−1).

# 1 Introduction 

Transportation networks are a major source of inspiration for graph-theoretic problems. A prominent example is the real-world problem of scheduling train trips across a network, where each train must be routed between a pair of nodes. This problem has spurred work in graph theory that accounts for various constraints that may arise. One of the foundational approaches to modeling this is the Edge Disjoint Paths (EDP ) problem [ 23 , 35 ]. In this scenario, we are given a graph G = ( V, E ) and pairs of vertices si, t i. The objective is to find a path from si to ti for each pair such that no two paths share an edge. This critical constraint prevents collisions between trains. However, the EDP problem has two deficiencies: (i) its disjointness constraint does not reflect how train tracks are actually used in practice, and (ii) the routing objective is more complex than findings paths between pairs of vertices. We discuss these two deficiencies in length, and propose how to fix them. Regarding deficiency (i), the schedule generated by the EDP solution assigns each edge to at most one train. This approach is unrealistic, because a track can accommodate multiple trains, as long as at most one occupies it at any given moment. Temporal graphs [ 33 ] provide a natural model for this aspect by allowing the same edge to be traversed at different time steps by different trains. A temporal graph G = ( G, λ ) generalizes a static graph G (called the footprint ) by equipping it with a labeling function λ : E(G) → 2N+

In this new setting, we can generalize the EDP problem as follows: Given a temporal graph G and pairs of vertices si, t i, the new objective is to find a path from si to ti for each pair, ensuring that no two paths share a temporal edge in G. This more faithfully captures the time-dependent nature of train conflicts. However, the model still does not correctly reflect the track availability. In a real-world network, the tracks are always passable, whereas the labeling function of a temporal graph artificially restricts at which time steps each edge may be used. Both the static and the temporal model thus have complementary shortcomings. The static model fails to account for the temporal dynamics of trains traveling along the network, while the temporal approach unnecessarily restricts the availability of edges. To combine the strengths of both methods, we propose working on a static graph G = ( V, E ) and source-destination pairs (si, t i), with the objective of finding temporal edge disjoint paths, i.e., no two paths traverse the same edge at the same time step, assuming unit travel time per edge. In addressing deficiency (ii), it is important to note that EDP fails to capture real-world train scheduling in three ways: (a) trains should serve specific passenger demands along their route, not merely an origin-destination pair; (b) passengers require connections at particular times, rather than at arbitrary ones; (c) a train may traverse the same track multiple times throughout the day. We address all three by extending the problem as follows: We are given a directed static graph G = ( V, E ), and a set of demands D of the form (u, v, t ), where 

(u, v ) ∈ E is an edge and t ∈ N+ is a time step. We denote by G(G, D ) the temporal graph where every edge of G is available at all time steps until Λ( D) = max (u,v,t )∈D t. The goal is to find the minimum number of temporal walks in G(G, D ) such that for every (u, v, t ) ∈ D

there is a walk that traverses the temporal edge (u, v, t ), and no two walks traverse the same temporal edge. We call this the Temporally Edge Disjoint Schedule Completion 

(TEDSC ) problem. 

Input: Directed static graph G, draft schedule D, integer k ∈ N.

Problem: Does there exist a schedule S in G(G, D ) with |S| ≤ k that extends D?

Temporally Edge Disjoint Schedule Completion (TEDSC) 

The name reflects the structure of the input and the objective: D is a draft schedule of required trips, each specifying an edge that must be traversed at a particular time, and the goal is to complete this draft schedule by finding walks that cover every demanded trip while remaining temporally edge disjoint . We call the resulting set of temporal walks a schedule .

TEDSC directly models the goal of minimizing the number of walks needed to serve all passenger demands. In practice, however, driver availability is often the binding constraint, as drivers are subject to legal working-time regulations. This motivates two constrained variants: First, the length-constrained ℓ-TEDSC problem, which adds the restriction that every walk can contain at most h edges. Second, the lifespan-constrained τ -TEDSC problem, where every walk is allowed to be active for no more than h time steps, meaning that the time difference between the start and end of a route cannot exceed h. Intuitively, ℓ-TEDSC 

upper bounds the amount of time that a train travels on tracks, whereas ℓ-TEDSC upper bounds the time spent traveling plus the time spent waiting at stations. # 1.2 Techniques and Proof Outlines 

In this section, we describe the techniques that we use to prove our results. One of the main ingredients that we use throughout the paper is the notion of static expansion from temporal graphs. In order to express the temporal dimension of our input graph G = ( V, E ),we create a new graph by creating Λ( D) + 1 many layers, where each layer contains one vertex copy for each of the n vertices. The vertex copy of a vertex u in layer i, represents vertex u at time step i. We will refer to such a vertex as time-vertex (u, i ). Every vertex in layer i has a directed edge to its corresponding copy in layer i + 1 . These edges express the ability of a walk to wait on a vertex for one time step, and we refer to them as waiting edges. Additionally, for every edge (u, v ) ∈ E and every layer i, we add a directed edge from (u, i )

Polynomial-time Algorithm for TEDSC . In Section 4, we give a polynomial time algorithm for TEDSC by reducing to a flow problem with upper and lower bounds on the flow on each edge. We construct our static expansion graph based on our input graph G = ( V, E ) and demands D. We add a source vertex s connected to the first layer, and a target vertex z that is connected to the last layer. We now add capacity constraints to the edges. The waiting edges have an upper bound of ∞. For the moving edges that are also demands, we put a lower and upper bound capacity of 1, while for the rest of them we only put an upper bound capacity of 1. The upper bound enforces that our walks will be edge disjoint, while the lower bound enforces that every demand edge will be covered by a walk. It is well known that for directed networks one can reduce the problem of finding flows with lower bounds to a regular flow problem [ 15 ] which can then be solved by any polynomial max-flow algorithm [ 17 ]. However, there is one important caveat. This algorithm is only pseudopolynomial in the number of demands |D|. In particular, if there are large gaps in time between demands, our static expansion may have exponential number of layers compared to the input. To account for this, we show that we can prune enough layers from the static expansion down to a desirable number while keeping a feasible solution. First, let a time step t be called a relevant time step if and only if D contains a demand edge at time step t.We show that if there is a feasible flow solution in the static expansion we just constructed, then there also is a feasible solution if we prune our static expansion, by removing layers such that there are at most (n − 1) · k layers between any two consecutive relevant time steps. Therefore, we now have a static expansion with at most |D|(( n − 1) · k) many layers without destroying all feasible solutions. Figure 3 shows an example of the compression. The transformation from BinPacking to ℓ-TEDSC is very natural: A bin of capacity B

is the same as a walk that can make B steps. In that sense, if an item i of size s(i) is packed into a bin, then the corresponding walk must travel a distance of s(i). An easy way to realize this setup is by building a tree whose root initially hosts all walks and whose branches are paths of length s(i). By placing demands at the ends of the paths at sufficiently spaced time steps, the work of traversing the branches is equivalent to placing the corresponding item into the corresponding bin. As the item sizes are encoded in unary, constructing the branches with s(i) vertices is still polynomial in the size of the UnaryBinPacking instance. It also shows that ℓ-TEDSC is W[1] -hard even on graphs of constant treewidth. Next, observe that all branches of the tree are only used once by one walk. If we place demands at the root of the tree that force all walks to return there in between handling the demands of the items, we can merge the branches of the tree into a single path. The walks are hosted at one end of the path and each item appears as a demand somewhere on the path. This simplification shows that ℓ-TEDSC is also W[1] -hard on graphs of constant pathwidth. Finally, we can simplify this construction even further by collapsing the entire path into a single edge. To ensure that each item i still requires s(i) steps, we add more than one demand. In particular, there are 2s(i) demands that direct a walk back and forth on the very same edge. To ensure that all these demands are fulfilled by the same walk, we introduce one additional vertex that serves as the waiting area for all other walks. However, ℓ-TEDSC has some extra necessary steps, so we begin by describing the solution for τ -TEDSC .First, we guess for each demand which walk is going to cover it. However, based on our problem formulation, we allow multiple walks to traverse the same waiting edge, whereas the algorithm by Golovach and Thilikos [18] does not allow this. To fix this, we replace every waiting edge with k many parallel edges, and then subdivide every edge of the graph. The subdivision step is important to guarantee that the final product is a simple graph and not a multigraph. For ℓ-TEDSC , the previous approach falters in two ways. First, the waiting edges of the static expansion do not contribute towards the length of each temporal walk. This means that while the lifespan of any walk between layers i and j is always j − i, the length of such a walk is not fixed. To amend this, apart from guessing which demands are covered by each walk, we also guess how many edges a walk uses between two consecutive demands assigned to it. > XP

Algorithm for ℓ-TEDSC and τ -TEDSC Parameterized by k. In Section 6.2, we show that ℓ-TEDSC and τ -TEDSC admit an XP -algorithm when parameterized by k. Since we showed that k < |D|, the algorithm also works when we parameterize by D.Our approach is the same for both problems, where we create a state graph . The state graph describes every possible state of the network based on (i) current time step and (ii) the state and position of every walk. Informally, the state graph contains a vertex for every possible combination of the following possibilities: (i) time steps from 1 to Λ( D) + 1 , (ii) the set of walks that have not started yet, (iii) the set of walks that are currently active, (iv) the position of the current walks, (v) the remaining length/lifespan of each walk. Formally, a state is a tuple (t, U, A, p, c ) where t ∈ [Λ( D) + 1] is a time step, U ⊆ [k] is the set of so-far unused walk ids, A ⊆ [k] \ U is the set of active walk ids, p : A → V (G) is the position profile of the active walks, and c : A → N is the capacity profile of the active walks. Additionally, we add a directed edge from a vertex s1 to a vertex s2 of the state graph if it is possible to transition from state s1 to state s2 in a valid solution. Informally, we need to make sure that the two states are compatible based on (i) their time steps, (ii) their set of inactive walks, (iii) the position and capacity of their active walks. We also need to make sure that the transition guarantees (a) temporal edge disjointness and (b) all demands are covered. All of these constraints are covered by the following formal definition. The state graph contains an edge from a state (t1, U 1, A 1, p 1, c 1) to a state (t2, U 2, A 2, p 2, c 2) if and only if all of the following hold: 

1. t2 = t1 + 1 .

2. U2 ⊆ U1.

3. A2 ⊆ A1 ∪ U1.

4. For every i ∈ A2 \ A1 we have c2(i) = h.

5. For every i ∈ A1 ∩ A2 it holds that

# 1.3 Outlook and Future Work 

In this paper, we have the studied the complexity of TEDSC , ℓ-TEDSC , and τ -TEDSC .We have completely explored the parameterized complexity landscape with regards to the parameters k, h, and |D| and showed that the constrained problems behave the same. We also showed that if we consider n as a parameter, then the complexity of the two problems is different. One immediate open question is whether our FPT algorithm by k on fixed bidirected stars can be generalized to trees. However, our proof heavily relies on the structure of star graphs, so we would need a different approach to generalize the result. There are also other natural next steps to consider. If we wanted to make the problem even more realistic, then we can consider extending it in different ways. First, we are currently assuming that travel time of every edge is 1, so one natural extension is to assume that different edges have varying travel times. Our negative results 12 Temporal Routing in Static Networks: The Schedule Completion Problem 

obviously extend to this setting, however, it is not clear whether our positive results would still hold. The second extension is based on the start and end points of the walks. We are currently assuming that the walks can start and end at any vertex. However, in real-world transportation networks, e.g. train systems, only a subset of the stations can serve as depots where the trains can start or end their trip. Therefore, we can extend the problem by assuming that as part of the input we are given a subset of the vertices where the walks can start or end, and study whether our computationally hard variants become tractable. Finally, we are currently assuming that any number of walks can be at the same station at the same time. This is an oversimplification of the real-world and we can extend the model by having as part of the input, a capacity for each vertex. 

# 1.4 Related work 

The problem of connecting pairs of terminal vertices using vertex or edge disjoint paths in static graphs is well studied. The notions of vertex and edge disjointness are very close as the two problems can be reduced to one another in polynomial time. In the case that all terminal pairs connect the same two vertices s and t, Menger’s theorem [ 30 ] tells us that the maximum number of disjoint paths equals the cardinality of the minimum cut. This is in turn the same as the capacity of the minimum vertex cut, which is the same as the maximum flow from s to t if all edges have unit capacity. If, on the other hand, the endpoints of the paths are specified separately for each path, the complexity changes drastically. The corresponding flow interpretation is that there are multiple so called commodities that need flow routed between them. Multicommodity flow is NP -complete, the first general proof of this was given by Donald Knuth in book by Karp [23] . Shortly after, Even et al. [12] showed that the problem is NP -hard even if there are only two commodities. Their reduction from SAT uses one commodity with a single flow unit to choose variable values and a second commodity with one flow unit for each clause to check the assignment. Recent work by Bodlaender et al. [3] studies the complexity of two-commodity flow parameterized by structural parameters. Finally, requiring a single commodity flow to adhere to lower bounds on edges makes the problem NP -hard on undirected graphs [ 20 ]. On directed networks, this requirement can be reduced to a normal flow problem [15]. The complexity of EDP parameterized by the number of paths k greatly varies be-tween directed and undirected graphs. In undirected graphs, Robertson and Seymour [35] , Kawarabayashi et al. [25] give FPT algorithms. In directed graphs though, the problem is notoriously hard. Fortune et al. [16] show that in general graphs, VDP is NP -hard even for 

k = 2 . For their reduction from SAT , they design a gadget called the switch which can be attached to two edges so that later on only one of those two edges can be used. Importantly, the two paths leave the switch again and can be reused in other parts of the graph, for example to power more switches. Recently, Cavallaro et al. [4] show that EDP parameterized by k on Eulerian directed graphs is in FPT . Chitnis [5] gives a tight lower bound for EDP 

on planar DAGs. When considering paths of bounded length, Menger’s theorem does not hold anymore [ 1,13 ], which means that finding disjoint paths and cuts are separate problems. Itai et al. [21] study the problem of finding disjoint paths of bounded length. They give an almost complete classification of the values of h for which the problem of finding vertex / edge disjoint paths of length equal / at most h is NP -hard. In particular they show that all variants are NP -hard starting with h = 5 . Golovach and Thilikos [18] study bounded length disjoint paths and cuts and give a complete characterization with regards to parameterizing by k, h, or both. The general study of temporal paths begins with work by Cooke and Halsey [7] who M. Döring, N. Mohrin, and G. Skretas 13 

study shortest temporal walks with varying travel times. Halpern and Priess [19] study shortest paths in temporal graphs and introduce what we today call the “static expansion” of a temporal graph. The term “temporal network” was first used by Kempe et al. [26] .Klobas et al. [28] study the problem of finding temporally disjoint walks connecting the given terminal pairs. They show that this problem is W[1] -hard when parameterized by 

k. Notably, in their problem each walk needs to connect a predetermined pair of vertices, whereas in our problem it is not fixed which demand is covered by which walk. Recent work by Deligkas et al. [9] studies a similar problem to the one posed here: Given a temporal graph, can it be exactly covered using k temporal walks? Thus, in their work the temporal network is given in its entirety and the walks cannot move on edges that are not demanded in the input. In the case of strict travel in directed networks (which is the closest to our setting), they give a polynomial time algorithm. Finally, Bhaskar et al. [2] introduce a train routing problem where a set of trains should be routed on temporal s-t-paths while maintaining a safe distance, the headway, between each other. The concept of headway is a generalization of temporal edge disjointness and also incorporates travel times, whereas in our problem all edges can be traversed in unit time. They study approximation algorithms for the problem of minimizing the makespan, that is, the latest arrival time among all trains. Another perspective on the TEDSC problem is as a realization problem, that is, a problem where a temporal graph should be constructed so that it fulfills some property. In our case, the sought graph would be the union of the temporal walks. While there is much ongoing work on temporal realization problems [ 11 , 29 , 32 ], we believe that none of it covers the problem studied here. The problem of finding flows over time (also called dynamic flows) [ 14 , 36 ] is tangen-tially related to the problems studied here. Particular problems like Quickest Flow and 

Earliest Arrival Flow use similar ideas, for example that of a time-expanded network, but optimize in the time domain instead of fixing it like the draft schedule of TEDSC . To the best of our knowledge, no equivalent problem to TEDSC has been studied in this area.

# 3 The Schedule Completion Problem 

Consider a rail network modeled by a static graph G, where each edge represents a track that can be used by at most one train at any given time. A draft schedule is a set D of demands, where each demand (u, v, t ) is a passenger request to travel from u to v at time step t. We define Λ( D) = max (u,v,t )∈D t as the lifetime of the draft schedule; when D is clear from context we write just Λ. We want to operate a small fleet of trains, each following a route 16 Temporal Routing in Static Networks: The Schedule Completion Problem 

through the network, such that all passenger requests are covered. Each train corresponds to a temporal walk, and since two trains cannot share the same track at the same time, the walks must be temporally edge disjoint. The schedule completion problem asks: how many trains suffice? Formally, since G is a static graph with all edges always available, we model it as the temporal graph G(G, D ) = ⟨G, λ D ⟩ where λD : e 7 → [Λ( D)] . # 3.1 Constrained variants 

The general schedule completion problem is a deliberate simplification of the real-world problem: trains can travel arbitrarily far and operate indefinitely. In practice, both constraints are bounded: the fuel capacity limits the distance a train can travel, and working-time regulations limit the time a train can operate. We study two variants of TEDSC that capture these restrictions, one for each constraint. The length-constraint bounds the number of edges a train may traverse. 

Input: Static graph G, draft schedule D, integers k, h ∈ N.

Problem: Does there exist a schedule S for D such that |S| ≤ k and ℓ(p) ≤ h for all p ∈ S?

The lifespan-constraint instead bounds the total active time of a train, i.e., the time between its first and last move.

Furthermore, the flow ranges ensure that these walks cover all demands in D and are temporally edge disjoint: Each demand edge e

has range (1 , 1) , which enforces that the corresponding demand is covered by exactly one walk, and that no two walks use the same temporal edge, i. e., the walks are temporally edge disjoint. Each remaining moving edge has range (0 , 1) , which enforces that no two walks share a temporal edge, but allows for the possibility that some temporal edges are not used by any walk. Lastly, the waiting edges and the edges from s and to z are unconstrained, allowing for any number of walks to wait in a vertex, to start at any vertex in the first layer, 20 Temporal Routing in Static Networks: The Schedule Completion Problem 

and to end at any vertex in the last layer. As a result, TEDSC is a YES-instance if and only if a feasible s-z-flow of value at most k exists in (̂ SE (G, D ), r ). Such a flow can be found in polynomial time with respect to the network size as discussed in Section 2.2. Note however that this time is pseudo-polynomial: the bound is polynomial in n and Λ, but Λ can be exponential in the bit-length of the input. ◀

# 5 Hardness of Constrained Schedule Completion 

Both ℓ-TEDSC and τ -TEDSC capture the complexity of notoriously hard problems. This is in part because finding edge disjoint paths of bounded length in static graphs is already 

> NP

-hard and we thus only need to remove the temporal aspect to capture this hardness. On the other hand, we can use the length- and lifespan-constraints to enforce a pairing of demands and thus capture the problem of connecting terminal pairs with edge disjoint paths. Finally, if we allow for a large number of demands, distributing the demands among the walks also captures the BinPacking problem, which leads to our most drastic hardness result.

# 7 Approximating the Number of Required Walks 

So far we studied the schedule completion problem as a decision problem. In this section, we switch perspective and investigate the corresponding search problem in which the output of an algorithm should be a schedule using the smallest possible number of walks. 

Input: Static graph G, draft schedule D, integer h ∈ N.

Problem: A schedule S that extends D, satisfies χ(p) ≤ h for all p ∈ S, and is of minimal size |S|.

▶ Definition 7.1 (τ -cost) . The τ -cost of an edge e = (( u, t 1), (v, t 2)) is cτ (e) := t2 − t1. ⌟▶ Definition 7.2 (ℓ-cost) . The ℓ-cost of an edge e = (( u, t 1), (v, t 2)) is cℓ(e) := dG(u, v ). ⌟
